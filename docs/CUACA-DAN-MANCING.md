# Sukarame 1.5 — Cuaca & Mancing Mania

Cuaca berganti otomatis setiap 100–180 detik waktu bermain. Urutannya diacak dalam kelompok sebelas kondisi dan tersimpan bersama progres. Jadwal invasi tetap terpisah: zombie bisa menyerang ketika banjir, dan petir bisa menyambar UFO ketika alien menyerbu.

| Kondisi | Pengaruh |
| --- | --- |
| Cerah | Cahaya terbuka dan perjalanan biasa |
| Berawan | Awan bergerak, sinar matahari meredup |
| Hujan | Rintik dan kabut hujan |
| Hujan badai | Hujan lebat diterpa angin, jarak pandang berkurang |
| Kabut asap karhutla | Kabut cokelat pekat mengurangi jarak pandang |
| Tornado | Pusaran bergerak mencari rumah, warga dan ternak; tarikan dan kerusakan dapat meruntuhkan rumah |
| Hujan salju | Butiran salju, permukaan bersalju, gerak darat 70% dan jejak kaki |
| Badai salju | Salju lebat diterpa angin, kabut, gerak darat 70% dan jejak kaki |
| Banjir | Jalan terendam air beriak, seluruh desa dapat dipancing, gerak darat 52% |
| Jalan bersalju | Salju menetap di tanah, gerak darat 70% dan jejak kaki |
| Hujan petir | Sambaran acak setiap 5–11 detik, kilatan cahaya, guntur dan api |

Perlambatan berlaku untuk pemain, tunggangan darat, warga, ternak, pasukan, musuh dan dinosaurus darat. Tunggangan terbang serta pesawat tetap bebas dari hambatan permukaan. Dalam minigame kondisi permukaan memengaruhi pemain maupun lawan; pergantian cuaca dan bahaya dunia dijeda bersama waktu desa. Rumah pemain dan ekspedisi antariksa juga menjeda simulasi desa.

Petir dapat mengenai rumah, bangunan, pohon, warga, ternak, pemain, hantu, zombie, alien, UFO dan dinosaurus. Api terlihat pada target dan terus melukai makhluk serta merusak rumah; bangunan umum dan pohon menampilkan kobaran tanpa hilang dari dunia. Banjir memadamkan api dekat tanah lebih cepat, tetapi atap, pucuk pohon dan pesawat masih bisa terbakar. Dekati titik api dan tekan **E** untuk memadamkan. Korban cuaca yang terluka bisa ditolong dengan **E**, tanpa biaya serum. Kotak jingga pada peta menunjukkan korban, lingkaran jingga menunjukkan tornado.

Pos ronda tetap menjadi tempat berlindung. Setiap fajar warga membangun kembali rumah yang rusak dan memulihkan warga/ternak, mengikuti sistem gotong royong yang sudah ada. Api serta cedera cuaca ikut dibersihkan.

## Memulai memancing

1. Beli **Joran Bambu (65 koin)** dan **umpan (3 koin)** di Kopdes.
2. Turun dari tunggangan, dekati tepi air dan tekan **E**. Saat banjir seluruh area desa menjadi spot.
3. Tunggu pelampung menyentak, lalu **E** atau tombol **Tarik**. Terlalu cepat, terlambat, atau bergerak menjauh akan menggagalkan tangkapan. Setiap lemparan menghabiskan satu umpan.
4. Setiap hasil tangkapan mendapat bobot dan panjang acak. Hansip mengangkat model ikan dan berseru **“Mancing Mania, Mantap!”**. Audio bahasa Indonesia dibundel lokal, bekerja offline, dan mengikuti pengaturan suara.
5. Buka **Bekal (I)** untuk melihat sepuluh jenis ikan, jumlah tangkapan, rekor bobot/panjang dan lima tangkapan terbaru. Hasil pancing dapat dijual per ekor di Kopdes atau disimpan di rumah. Rekor tetap ada setelah ikan dijual.

## Upgrade Pak Bowo

Temui **Pak Bowo, Guru Pemancing**, di tepi barat sungai **(140, −77)**. Tombol **Temui Pak Bowo · upgrade joran** di Bekal memasang penanda tujuan. Ia tersedia siang dan malam.

Terima quest **Rahasia Joran Tirta** untuk memperoleh 12 umpan. Tangkap **enam ikan apa saja setelah menerima quest**, lalu kembali untuk mengambil **Joran Pusaka Tirta**, 90 koin dan 2 sari gaib. Pembelian ikan tidak dihitung sebagai tangkapan. Hadiah tidak dapat diambil berulang.

Reel Koperasi adalah upgrade toko tingkat dua; Joran Tirta tingkat tiga hanya didapat dari quest. Keduanya memperpanjang waktu menarik menjadi 3,5 detik dibanding 2 detik pada Joran Bambu.
