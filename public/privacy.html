Privasi Ronda Malam

Diperbarui 8 Oktober 2026.

Game ini dimainkan tanpa akun. Progres, pilihan suara, dan pengaturan visual disimpan di perangkat melalui penyimpanan browser. Game tidak mengirim progres ke server dan tidak memasang analitik, iklan, atau pelacak.

Service worker menyimpan berkas game agar dapat dimainkan offline setelah unduhan pertama selesai. Hosting menerima permintaan jaringan biasa saat membuka atau memperbarui game; pencatatan akses mengikuti kebijakan penyedia hosting.

Ekspor save mengunduh berkas JSON ke perangkat. Impor hanya membaca berkas yang Anda pilih dan mengganti progres lokal. Berkas tersebut tidak diunggah. Tombol mulai ulang menghapus progres permainan; penghapusan data situs di browser juga menghapus save dan cache offline.

Audio dibuat di perangkat. Game tidak mengakses mikrofon, kamera, lokasi, kontak, atau identitas perangkat. Tidak ada pembelian dalam aplikasi.

Salin save melalui Pengaturan → Ekspor save sebelum berpindah browser, perangkat, atau alamat situs. Simpan file tersebut secara pribadi.
